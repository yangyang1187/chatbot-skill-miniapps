# xiaocx-miniapp 小程序技能包

一套娱乐/实用小程序命令，通过统一脚本调用，输出结构化 JSON。

## 调用方式

用本技能自带的通用入口（自动定位仓库和解释器）：

```bash
bash <技能目录>/scripts/runner.sh <命令名> [参数...]
```

输出 JSON：`{"ok": bool, "command": str, "text": str, "images": [url], "error": str}`

- `ok` 为 true：把 `text` 原样发给用户；`images` 里的 URL 作为图片发给用户（markdown `![](url)`）。
- `ok` 为 false：把 `error` 转述给用户，不要重试超过一次。
- 不要把 JSON 原文直接贴给用户。

## 命令与参数映射

| 用户意图 | 命令与参数 |
|---|---|
| 查天气「北京天气」 | `天气 北京`（默认北京） |
| 抽塔罗牌 | `塔罗牌` |
| 疯四文案 | `kfc` |
| 吃什么 | `今天吃什么` |
| 看猫/看图/二次元 | `猫猫图片`、`二次元图片`、`随机头像`、`必应壁纸 [偏移]` |
| 舔狗日记/骚话/励志英语/弱智吧 | 同名命令，无参数 |
| 藏头诗 | `藏头诗 <文字>`（最多4字） |
| 运势「天蝎座运势」 | `运气 天蝎座` |
| 摸头 gif「摸头 123456」 | `摸头 <QQ号>` |
| 俄式轮盘 | `轮盘赌`；用户要继续时传 `轮盘赌 继续` |
| 方舟抽卡「来发十连」「抽30发」 | `明日方舟十连 [次数]`（默认10，最多60） |
| 以图搜图 | `搜图 <图片URL>`——用户在聊天里发了图或回复了一张图时，把该图 URL 传进去 |
| Pixiv 插画 | `pixiv图 <插画ID或URL> [页码]` |
| B 站直播间「看下 21452505 直播间」 | `B站直播 <房间号>` |
| 画图 | `画图DALL·E-3 <描述>`、`画图OpenAI <描述>`、`画图ideogram版 <描述>`（需相应 API key，未配置时如实告知用户缺什么） |

不确定命令是否存在时先跑：`bash <技能目录>/scripts/runner.sh --list`

## 注意

- 参数含空格/URL 时作为一个参数整体传入。
- 联网命令偶发失败（`所有数据源都失败了`），可直接重试一次再告知用户。
- R-18/Pixiv 大图等依赖环境变量的能力未配置时，如实说明而不是猜测。
